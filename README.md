# C Programlama Dersleri ve Pratiklerim

Bu depoda, Fedora Linux ortamında GCC derleyicisi kullanarak C dilini öğrenirken yazdığım ders kodlarını ve pratik çalışmaları paylaşıyorum.

## 📚 Ders Listesi

- **ders0001.c:** Ekrana yazı yazdırma
- **ders0002.c:** Toplama işlemi
- **ders0003.c:** Tam sayılarda toplama işlemi
- **ders0004.c:** Ondalıklı sayılarda toplama
- **ders0005.c:** Tam sayılarda fark işlemi
- **ders0006.c:** Ondalıklı sayılarla fark işlemi
- **ders0007.c:** Tam sayılarda karışık toplama ve çıkarma işlemi
- **ders0008.c:** Ondalıklı sayılarla karışık toplama ve fark işlemi
- **ders0009.c:** Çarpma işlemi
- **ders0010.c:** Karışık toplama ve çarpma işlemi
- **ders0011.c:** Bölüm işlemi
- **ders0012.c:** Karışık işlemler (toplama, çıkarma, çarpma, bölme)

## 🏋️ Pratik Çalışmaları (Practice)

- **practice0001.c:** Ekrana yazı yazdırma pratiği
- **practice0002.c:** Toplama işlemi pratiği
- **practice0003.c:** Tam sayılarda toplama pratiği
- **practice0004.c:** Ondalıklı sayılarda toplama işlemi pratiği

---

## 🛠️ Çalıştırma Komutları

Herhangi bir C dosyasını derlemek ve çalıştırmak için terminalde şu komutları kullanabilirsiniz:

```bash
gcc dosya_adi.c -o dosya_adi
./dosya_adi
